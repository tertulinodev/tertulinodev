Desenvolvo dashboards dinâmicos no Microsoft Excel para suporte à tomada de decisões e conduzo análises estatísticas complexas com manipulação e consultas estruturadas em bancos de dados relacionais.
- **Diferencial Competitivo (Letras):** Minha formação acadêmica atua como um acelerador estratégico na tecnologia, conferindo precisão cirúrgica para a redação de documentações técnicas de alta clareza (APIs e arquitetura), revisão textual rigorosa e comunicação interpessoal altamente assertiva entre equipes de Engenharia, Design e Produto.
